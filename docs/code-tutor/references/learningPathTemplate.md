# 学习路径

| 阶段 | 实践 | 完成标准 |
| --- | --- | --- |
| 入口 | 阅读配置和服务启动 | 能说明 JWT 先校验、何时监听、如何关闭 |
| 请求 | 追踪登录和一次聊天 | 能区分用户身份、管理权限、SSE 和错误 |
| 状态 | 阅读任务与会话 | 能识别用户/任务归属、并发快照和取消边界 |
| 存储 | 跟踪一次记忆事务与投影 | 能解释强一致范围、至少一次与单消费者限制 |
| 修改 | 复现一个小问题并修复 | 测试证据、明确差异和有意义的独立 commit |

完成后再选择 PDF、RAG、Skill 或沙箱模块深入。使用本机合成数据；真实服务验收另行准备隔离环境。
