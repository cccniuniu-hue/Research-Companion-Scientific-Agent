# 本项目术语

| 术语 | 含义与边界 |
| --- | --- |
| context | 传递请求身份、期限和取消；不能撤回已完成的外部操作 |
| DAG | 有依赖关系的任务图；重试/竞速仍需工具幂等 |
| RAG | 检索资料后组织回答；引用存在不证明内容正确 |
| Outbox | 与权威记忆一起事务提交的待投影事件；不是跨库事务 |
| 投影 | 从权威状态构造查询视图，需要版本规则与恢复 |
| SSE | 服务器到浏览器的事件流；部分文本不等于完整成功 |
| Skill | 用户安装的 Prompt/工具定义；不是下载执行 GitHub 代码 |
| mock | 可控的测试或演示实现；不是实际外部执行 |
