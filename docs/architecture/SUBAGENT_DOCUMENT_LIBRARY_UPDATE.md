# 子 Agent 与文档库

应用层 `internal/application/chat/` 包含 research、writer、review、doc 子 Agent。图节点记录执行器类型、名称和目标，上游结果带节点/执行器标识；doc 节点选择明确的 writer 输出并保存 Markdown，再尝试 RAG 入库。

常见链路为 research → writer → review → doc，但实际图由请求规划和重规划决定，不能保证每次都生成完全相同的 DAG。研究结果可来自知识库、搜索或明确标注的降级回答；未配置真实模型/搜索时不能宣称获得实时证据。

任务 user_id 从可信 context 绑定；图恢复拒绝外部用户和无归属旧任务。每层完成后协调结构变更，当前视图和快照复制可变内容。工具结果和文档产物分别记录，不应把 mock 命令输出当作真实文件执行结果。

文档库为共享管理数据。用户身份元数据用于审计，不自动提供文档级授权。普通浏览器具备查看器组件但没有内置管理凭证。产物根目录在容器中固定为 `/app/.data/artifacts`；部署者仍需校验目录所有权、路径范围和实际 Docker 挂载行为。

取消是协作式的，已完成的搜索、SQL、文件写入或外部工具操作不可撤回；重试和竞速也不是 exactly-once。真实模型、数据库、文件权限与恢复流程需要额外验收。
